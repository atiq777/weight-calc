# ওজন হিসাব

দাম আর ওজন দিলে মোট টাকা হিসাব করার Android অ্যাপ (Flutter)।

## APK বানানোর নিয়ম
1. এই ফোল্ডারের সব ফাইল (`.github` ফোল্ডারসহ) GitHub রিপোজিটরিতে আপলোড করো
2. রিপোজিটরির **Actions** ট্যাবে `Build APK` নিজে থেকে চলবে (না চললে "Run workflow" চাপো)
3. সবুজ টিক এলে ওই রানে ঢুকে নিচে **Artifacts** থেকে `weight-calc-apk` নামাও
4. জিপ খুলে `app-release.apk` ফোনে ইনস্টল করো
